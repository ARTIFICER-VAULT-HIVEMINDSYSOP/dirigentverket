# IPO-paper · ram (marknad)

**Status:** paper. Inga påhittade kurser, kronor, mål eller prognoser. Live-utskick bara efter namngivet ja + lista.

## Lås
- Marketing producerar faktiskt inflöde; ARTIFICER räknar inte revenue-target (ÖB 2026-09-05).
- Nyhetssele/recept: IPO · olja · guld + prova-först + disclaimer (`marknad/NYHETSSELE.md`, `RECEPT.md`).
- Tom cell = saknas, inte noll.

## Paper-ram per IPO-rad
| Fält | Regel |
|------|--------|
| Bolag / ticker | Bara från öppen källa samma dag |
| Status | öppnar / pågår / saknas |
| Källa | namngiven URL eller medium |
| Kluster-koppling | education / prova-först — aldrig råd |
| Belopp / kurs | fylls bara om källan har den; annars `saknas` |

## Arbetsflöde
1. Samla öppna IPO-rader till dagens paper-utkast under `marknad/nyhetsbrev/` (om mappen finns).
2. Preview till ÖB. Ingen auto-send.
3. Live mejl bara efter ja på namngiven mottagarlista.

## Inte
- Påhittade IPO:er, kurser, SEK
- Personlig investeringsrådgivning
- Utskick utan namngivet ja
