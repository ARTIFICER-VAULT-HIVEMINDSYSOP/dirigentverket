Traderider — open this folder in Chrome or Edge
=============================================

Double-click index.html. No server and no internet are required.

The chart uses the NVDA candles bundled in this file. Yahoo is not contacted.
The broker panel is off. Orders stay in this browser's paper book.

Keys: W buy, S sell, F flat, [ ] leverage, Space pause.
Buttons on the page do the same thing.
